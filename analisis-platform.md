# Analisis Komparatif Platform

## Tabel Analisis Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C#, C++ | Java, Kotlin, Dart |
| Arsitektur | Client-server | Standalone atau client-server | Client-server |
| Cara distribusi | Melalui browser dan internet | Installer atau file executable | Play Store, App Store, atau file APK |
| Keunggulan | Mudah diakses tanpa instalasi dan dapat digunakan di berbagai perangkat | Performa tinggi dan fitur yang lebih lengkap | Praktis, mudah dibawa, dan dapat memanfaatkan fitur perangkat |
| Keterbatasan | Bergantung pada browser dan koneksi internet | Perlu instalasi dan biasanya bergantung pada sistem operasi | Terbatas pada ukuran layar, baterai, dan sumber daya perangkat |
| Contoh aplikasi | Google Docs, Gmail, Google Drive | Microsoft Word, Visual Studio, VLC Media Player | WhatsApp, Instagram, TikTok |

## Kesimpulan

Setiap platform memiliki karakteristik, keunggulan, dan keterbatasan yang berbeda. Platform web lebih mudah diakses melalui browser tanpa instalasi. Platform desktop unggul dalam performa dan kelengkapan fitur. Sementara itu, platform mobile lebih praktis karena dapat memanfaatkan fitur perangkat seperti kamera, GPS, dan notifikasi.

Selain itu, aplikasi web dapat diperbarui tanpa mengharuskan pengguna memasang aplikasi baru secara manual.

Dengan latihan rutin, saya berharap dapat meningkatkan kemampuan pemrograman, lebih mandiri dalam menyelesaikan masalah, dan lebih siap mengerjakan proyek berikutnya.
